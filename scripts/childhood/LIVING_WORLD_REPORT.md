## 本轮 18 项说明

1. **统一对白**：`DialogueTrack` 负责文字进度，`ChildhoodDialogue` 负责显示。所有原有对白及结尾两句话共用这一机制；无对白的父亲肚皮记忆保持无对白。
2. **中文速度**：普通字约 35–55 ms；逗号类标点额外 130 ms，句号/问号/感叹号额外 220 ms，省略号额外 340 ms。逐个 Unicode 字符显示，每帧最多一个字。
3. **快速显示**：E、Space、点击对白第一次补全当前句，第二次才推进。初次 300 ms 保护，后续 320 ms 防连按；原 Memory 动画时长仍保留，不能靠连按瞬间跳完整段。
4. **互动密度**：只有距离小于 32 世界单位、站稳地面时显示最近的一个提示。原范围为 58。普通互动与 Memory 使用不同的数据类型和处理分支。

## 回头看的情绪细节

- 普通待机随机池中，回头看的选择权重为 8%；ACT 05 为 28%。另有 48% 的动作触发门槛，以及 20–34 秒动作冷却，因此不会连续回头。
- 正常回头约 1.1 秒：头部轻转向身体朝向的反方向，脚和躯干保持行走朝向。动作结束恢复原 idle。
- 最终入口前停下约 3.8 秒，可出现一次 1.45 秒的回头；每次打开游戏仅一次，并尊重已有冷却。没有对白、弹窗、系统说明或剧情锁定。
- 该状态不修改速度、位置、行走朝向。左右移动、跳跃、互动、切场景或暂停都会中断；不会等待动作播放结束。

# Leo's Childhood · 第一版本地验收

日期：2026-09-08。实现范围限于 Childhood、其阅读器接入和新增资源。未 git push，未发布。

## 本地查看

打开 http://localhost:3000/other-side，进入 Room，点击原 Childhood 墙面，再点击「探索童年世界」。首次进入显示 PRESS START；有本地存档时显示 CONTINUE。

左／右或 A／D 移动，空格／W／↑ 跳跃，E／S 互动，Esc 打开菜单或退出记忆册。手机有独立方向、跳跃、互动按钮。顶部一直保留「返回 Leo's Room」。

## 测试与限制

- `verify-engine.cjs`：运动、跳跃、按住不连跳、石台落地与走下、镜头跟随、全部事件和门、前置条件、18 页解锁、重复事件去重、存档恢复与坏存档回退。
- `verify-browser.cjs`：真实 Chrome 中从 Room 墙面进入、完成两段记忆、记忆册仅两页可读并从第 1 页跳到第 4 页、Esc 返回、父亲肚皮与雪天早餐截图、手机返回 Room；浏览器 pageerror 为零。
- `verify-controls.cjs`：按需加载、触屏移动／同时跳跃／松手停下、横竖屏返回、退出移除按键监听并恢复背景交互。
- 原故事图片及故事数据的 Git 差异检查为空。

这是可玩的第一版。伙伴活动采用短互动动画，共用部分动作，没有做成独立复杂小游戏。学校和结束段保持较小规模；门和楼梯是可交互的场景连接，没有实现连续垂直攀爬。声音沿用现有 GlobalAudioProvider 和 childhood.mp3，未新增环境音轨。手机验证使用 Chrome 触屏模拟，尚未在真实 iOS／Android 设备上检查。
